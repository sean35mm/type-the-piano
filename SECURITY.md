# Security Policy

## Supported versions

Security fixes are applied to the current default branch. This project does not maintain separate release branches.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting form:

https://github.com/sean35mm/type-the-piano/security/advisories/new

Include reproduction steps, affected browsers or environments, impact, and any suggested mitigation. You should receive an acknowledgement within seven days. Please allow time for investigation and a coordinated fix before public disclosure.
